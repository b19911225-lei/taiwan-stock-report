# 判決全文批次檢索工具

## 為什麼要你自己在本機跑

撰寫這份工具的雲端工作環境，其網路出口政策對下列主機一律回 **403（policy denial）**，
不是連線失敗，是被組織政策擋掉，無法繞過：

```
judgment.judicial.gov.tw   data.judicial.gov.tw   opendata.judicial.gov.tw
www.judicial.gov.tw        law.judicial.gov.tw    law.moj.gov.tw
lawsnote.com               www.lawbank.com.tw     evaluation.org.tw
law.fsc.gov.tw             law.lia-roc.org.tw     lawplayer.com
```

所以判決全文必須在**你自己的電腦**上抓。抓完把 txt 丟回來，我再做要旨整理與函稿整合。

## 使用方式

```bash
pip install requests
python fjud_search.py --kw "年金保單價值準備金 and 受益人" --out ./judgments
```

Windows 可直接雙擊 `run_all.bat`（會依序跑完下列六組檢索）。

輸出：每篇一個 `.txt`（含法院、字號、日期、案由、來源網址與全文），
另有 `index.csv` 彙整清單。

## 驗證狀態（請務必先看）

- **解析邏輯已離線測試通過**（表單欄位探測、結果頁連結擷取、全文去標籤、
  字號擷取、檔名清理）。
- **與司法院線上系統的實際互動未經驗證** —— 環境連不上，無法實測。
  司法院系統是 ASP.NET WebForms，欄位名稱偶有調整。
- 若查詢失敗，請加 `--debug ./dbg` 重跑，開啟 `dbg/01_default.html`
  找出關鍵字輸入欄位的真實 `name`，回填腳本中的 `FIELD_HINTS`。
- 若仍不行，改用檔尾註解說明的 Playwright 瀏覽器方案，或直接用網頁 UI 手動檢索。
- 預設每次請求間隔 1.5 秒，請勿調低。

## 建議檢索字串（本案）

| # | 檢索字串 | 目的 |
| --- | --- | --- |
| 1 | `年金保單價值準備金 and 受益人` | 核心爭點 |
| 2 | `未支領之年金餘額 and 繼承人` | 保證期間給付對象 |
| 3 | `年金給付開始日 and 身故受益人 and 保單價值準備金` | 最貼近本案事實 |
| 4 | `遞延年金 and 受益人 and 遺產` | 遺產性質之認定 |
| 5 | `保險金 and 非受益人 and 清償效力` | 給付錯人不生清償效力 |
| 6 | `保險法第135條之3 and 受益人` | 準用第 112 條之適用 |

建議另以網頁 UI 手動查：

- 財團法人金融消費評議中心「評議決定書」公開查詢（爭議類型：年金保險—給付對象）
- 金管會保險局就年金保險身故給付對象之函釋
- 富邦人壽「金開鑫利率變動型年金保險（甲型）」送審條款歷次版本
